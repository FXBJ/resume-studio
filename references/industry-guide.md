# 六套行业模板指南

选模板只问一句：「你投什么行业？」然后对照下表。**不要拿设计风格让用户猜。**

| key | 行业 | 模块顺序 | 视觉 | 措辞偏好 |
|---|---|---|---|---|
| `tech` | 互联网 / 软件 / 技术 | 简介 → 技能 → 经历 → 项目 → 教育 → 证书 | 蓝色，色块栏题 | 技术栈 + 指标变化 |
| `product` | 产品 / 运营 / 市场 | 简介 → 经历 → 项目 → 技能 → 教育 → 证书 | 绿色，下划线栏题 | 策略 + 用户/业务指标 |
| `design` | 设计 / 创意 / 内容 | 简介 → 项目 → 经历 → 技能 → 教育 → 证书 | 紫色，纯文字栏题，可放头像 | 作品 + 场景 + 影响力 |
| `finance` | 金融 / 咨询 / 法律 | 简介 → 教育 → 经历 → 证书 → 技能 → 项目 | 衬线字体，编号栏题 | 规模感 + 严谨表述 |
| `engineering` | 制造 / 工程 / 医疗 / 基建 | 简介 → 经历 → 项目 → 教育 → 证书 → 技能 | 石墨蓝，色块栏题 | 技术规范 + 交付结果 |
| `public` | 国企 / 事业 / 教育 / 公共部门 | 简介 → 教育 → 经历 → 证书 → 技能 → 项目 | 绛红，衬线，庄重 | 责任 + 服务对象 + 成效 |

## 为什么这样排模块

**技能前置（tech）**：技术岗初筛靠关键词命中，HR 与 ATS 都在前 10 秒找技术栈。
**教育前置（finance / public）**：这两个行业对学历、院校、证书有传统权重，
后置会让第一屏看不到关键信息。
**项目前置（design）**：设计岗看作品，项目就是作品本身。
**证书前置（finance / public）**：CPA、法考、教资这类是硬门槛，必须显眼。

## 用户说「我不确定投哪个行业」

按 ta 描述的岗位内容判断，不要反问。判断依据：
- 写代码 / 系统 / 数据 → `tech`
- 谈需求 / 用户 / 增长 / 内容 → `product`
- 出图 / 版式 / 视频 / 文案 → `design`
- 报表 / 尽调 / 合规 / 案头 → `finance`
- 产线 / 工艺 / 临床 / 施工 / 质量 → `engineering`
- 体制内 / 学校 / 医院行政 / 公共服务 → `public`

## 一岗一版

同一份 raw 投不同行业，**换主题 + 调 module_order + 换措辞偏好**，
事实不动。例：同一个「做过数据看板」的经历：
- 投 `tech`：强调技术栈与性能指标
- 投 `product`：强调决策支持与业务结果
- 投 `engineering`：强调规范符合性与交付验收

这就是「一岗一版」——不是编三份简历，是同一份事实的三种讲法。
