# bullet 撰写规范

一条 bullet = **动作 + 对象 + 结果**。三者缺一就弱一分。

## 公式

```
[强动词] + [具体对象/范围] + [方法或工具] + [可核验结果]
```

示例演进：

| 版本 | 问题 |
|---|---|
| 负责后台系统开发 | 职责描述，没有对象规模和结果 |
| 参与了订单系统的优化工作 | 「参与」「工作」两个废词 |
| 使用 Redis 缓存优化订单查询接口 | 有动作有方法，缺结果 |
| 用 Redis 缓存重构订单查询接口，P99 从 800ms 降到 120ms | 完整 |

## 强动词分级

**一级（优先）**：设计、搭建、重构、主导、独立完成、从零构建、定位并修复、交付、上线
**二级（可用）**：优化、推动、建立、制定、支撑、覆盖、验证、输出、协调
**三级（尽量替换）**：参与、协助、负责、配合、跟进——这些词的问题是无法体现你的独特贡献

## 数字的四种形态

没有精确数字时，按优先级退化：

1. 精确数：`P99 从 800ms 降到 120ms`
2. 量级：`日订单从万级到十万级`
3. 范围：`覆盖 12 个业务方、3 个大区`
4. 交付物本身：`输出 32 页迁移文档，被 4 个团队复用`

**退化到第 4 级也没有时，标 `【待补】`。** 不要写「效果显著」这种不可核验的词。

## 每条 bullet 的红线

- 不超过两行（约 60—80 个中文字符）
- 不写「——」，拆句或用分号
- 不以 `-ing` 或「正在」结尾
- 不同时出现两个主语
- 不把团队成果全部归给自己（用「主导」「独立」与「参与」区分）

## 不重复原则（压一页的第一手段）

**「专业技能」栏已经列过的技能，不要在工作经历 bullet 里再枚举一遍。**

反例（同一份简历里技能栏已列「树脂修复 / 根管治疗 / 牙拔除术」）：
> 熟练掌握配台、四手操作、龈上洁治、牙周 GBT 刮治、树脂修复、牙体预备、全瓷冠及嵌体、贴面粘接、iTero 口扫……

正例：
> 协助带教老师日均接诊 10+ 人，独立完成牙体预备与全瓷冠粘接

判断标准：删掉这条 bullet，读者会少知道一件**只属于这段经历**的事吗？
不会，就删——它只是在重复技能栏。

实测收益：一份 4 段经历的医生简历，删掉 3 条重复枚举 bullet 后，
内容高度从约 320mm 降到 300mm，再配合 `font_scale=0.90` 即从两页压到一页。

## 自我提问（写完每条问一遍）

1. 删掉这条，HR 会少知道一件关于我的事吗？（不会就删）
2. 这条换个人名还能用吗？（能就太泛了）
3. 数字的来源我能说清吗？（说不清就标【待补】）

## 简介（summary）四要素

```
身份定位 + 领域/行业 + 年限或阶段 + 最强的一条证据
```

例：`3 年 B 端前端经验，专注复杂表单与数据可视化场景；
主导过 2 个从零到一的后台系统，最大单应用日活 4 万。`

不写「性格开朗、学习能力强、抗压能力强」——这些占了宝贵位置却不传递信息。
